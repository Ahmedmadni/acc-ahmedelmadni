## Source exceptions

- The attached PDF omits the printed key and explanation in **five** questions: 16.1.19, 18.2.4, 18.3.5, 19.2.28, and 20.2.26. Their answers are reasoned inferences and are marked `answerStatus: "inferred"`; the practice UI discloses this after answering.
- The PDF omits one or more distractors in **five** questions: 14.4.2, 15.8.23, 17.2.15, 17.2.25, and 19.2.12. Independently written alternatives occupy the missing positions; `sourceTextStatus: "reconstructed"` and the practice UI disclose these replacements. They are not claimed to be exact publisher text.
- Split question numerals, missing choice labels and multicolumn cases required manual normalization. Shared fact patterns are attached to their related questions. Fifteen two-column Karmee/Easecom/Clear Plus/Funtime questions are condensed into verified numerical case facts and marked `table-reflowed`; three more items with missing option letters bear the same status.
- Additional dense, multicolumn financial tables would benefit from visual editorial review. An independent text comparison verifies the recorded fragments, but does not certify that every chart is ideally typeset for every screen size.

## Reproducible checks

```sh
python scripts/import-cma-mcq-vol2.py "/path/to/Gleim 2025 MCQ bank Vol 2.pdf"
python scripts/audit-cma-mcq-vol2.py "/path/to/Gleim 2025 MCQ bank Vol 2.pdf"
npm run cma:check-content
npx tsc --noEmit
```

The independent audit reads the printed table of contents and an independent PDF text engine. It checks contiguous numbering per section, eight excerpts per question, and every printed answer key. The ten source JSON files are generated by the import script; do not silently replace flagged cases with guessed publisher text.

Latest audit: **11,023 of 11,064** independent source excerpts matched. The remaining **41** have explicit page-break, table-reflow, authored-replacement, or missing-answer reasons in `audit-cma-mcq-vol2.py`. All **1,378** printed answer keys matched; five missing keys are marked as inferred.
